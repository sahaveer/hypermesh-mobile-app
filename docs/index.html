Hypermesh Media Player & Hub

Open-source peer-to-peer Wi-Fi mesh media player for Android and self-hosted FastAPI + yt-dlp personal media hub. Stream, share, and download audio & video across your devices with zero mobile data.

Download Android APK Mobile App Repo Media Hub Server Repo

P2P Wi-Fi Mesh Radar

Phones on the same Wi-Fi or hotspot discover each other automatically over UDP/mDNS and pool music & video libraries in real time.

Self-Hosted Media Hub

Turn any Windows PC, Linux laptop, Raspberry Pi, or Android Termux device into a FastAPI + SQLite media server with HTTP 206 streaming and DLNA.

Built-In yt-dlp Importer

Download audio and video from YouTube and 1,000+ supported sites straight to your Hub library or pin offline copies directly on your phone.

Tailscale & Tunnel Ready

Access your personal media hub anywhere over encrypted Tailscale P2P mesh or temporary Cloudflare Tunnels without paying for cloud storage.

Open-Source Repositories

  • sahaveer/hypermesh-mobile-app — Flutter Android & cross-platform client, Mesh Radar, offline pinning, and official signed APK releases.
  • sahaveer/hypermesh-media-hub — Self-hosted FastAPI Media Hub, Web PWA, TV UI, DLNA discovery, and yt-dlp + FFmpeg downloader.
